Os 5 Passos do Multiciclo

  1. 1. Busca (Fetch): IR = Mem[PC]; PC = PC + 4;
  2. 2. Decodificação: A = Reg[rs]; B = Reg[rt]; ALUOut = PC + (ext << 2);
  3. 3. Execução:
    • R-type: ALUOut = A op B;
    • LW/SW: ALUOut = A + ext;
    • BEQ: if (A == B) PC = ALUOut; (termina)
    • Jump: PC = PC[31:28] & (IR[25:0]<<2); (termina)
  4. 4. Memória / Write-Back R:
    • R-type: Reg[rd] = ALUOut; (termina)
    • SW: Mem[ALUOut] = B; (termina)
    • LW: MDR = Mem[ALUOut];
  5. 5. Write-Back LW: Reg[rt] = MDR; (termina)

Fórmulas de Desempenho

Tempo de Execução (CPU Time):
T = N × CPI × T_clock = (N × CPI) / f
CPI Ponderado (Multiciclo):
CPI_médio = ∑ (Frequência_i × CPI_i)
Ciclos por Instrução (MIPS Padrão):
LW = 5 ciclos
SW = 4 ciclos
Tipo R = 4 ciclos
BEQ = 3 ciclos
Jump = 3 ciclos
Speedup (Aceleração):
Speedup = T_monociclo / T_multiciclo
Caminho Crítico Monociclo:
T_ciclo ≥ t_IMem + t_RegRead + t_ALU + t_DMem + t_RegWrite
(Instrução mais longa: sempre LW!)

Questões da Prova Real (UFSM)

PROVA Q1 Q1: add3 $rd, $rs, $rt (3.0 pts)

rd = rs + rt + rd (Monociclo). 3ª porta de leitura e 2ª ULA/somador.

PROVA Q2 Q2: subabs $rd, $rs, $rt (3.0 pts)

rd = |rs - rt| (Monociclo). Bloco módulo condicional ao bit de sinal 31.

PROVA Q3 Q3: relu $rs (4.0 pts)

if (rs > 0) rs = rs else rs = 0 (Multiciclo). Novos estados e expansão de RegDst.
